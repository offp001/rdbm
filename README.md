# RoUtils

## Features

* **3D preview** – View meshes/models
* **Image preview** – Small and large previews for PNG/image assets
* **Audio preview** – Preview OGG/MP3 assets
* **Export** – Export Caches

  * `Full Blob`
  * `RBXM`
  * `Image`
  * `Copy / Save Hash`
* **R6 to R15 Animations** – Convert R6 Animations to R15 Animations
* **RBXM to RBXH Blob** – Convert RBXM Files to RBXH Blob
* **FFlag Manager** – FFlag injector (FFlag injectors interacts with roblox memory it means you can get banned for using these, but its undetected.)

## Requirements

* Python 3.9+
* `Pillow` (required)
* `lz4` (required for cache/RBXM decompression)
* `numpy` (for mesh processing)
* `zstandard` (only for reading ZSTD-compressed RBXM blobs; optional)
* `DracoPy` (only for v6/v7 mesh preview; optional)

## Installation

1. Install **Python 3.9+**.
2. Download or clone this repository.
3. Open `install_requirements.cmd` (It will download requirements and will open routils.pyw.)
